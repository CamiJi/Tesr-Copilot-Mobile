# Tesr-Copilot-Mobile

Landing page statique avec déploiement automatique sur GitHub Pages.

## Activer GitHub Pages (source: GitHub Actions)

1. Ouvrir le dépôt sur GitHub.
2. Aller dans **Settings** > **Pages**.
3. Dans **Build and deployment**, choisir **Source: GitHub Actions**.
4. Vérifier que la branche par défaut est `main`, puis pousser un commit : le workflow déploiera automatiquement la page.
